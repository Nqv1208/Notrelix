# Database Migration Helper

Generate EF Core migrations with proper entity configurations, indexes, and naming conventions.

## When to Use

- Adding new entities to the database
- Modifying existing entity properties
- Adding indexes or constraints
- Need to follow Notrelix database conventions automatically

## What This Skill Does

1. Generates EF Core migration files
2. Creates entity configuration (IEntityTypeConfiguration)
3. Adds proper indexes (with partial filters for soft delete)
4. Follows snake_case naming conventions
5. Includes fractional indexing for position fields
6. Sets up JSONB columns for flexible properties

## Prerequisites

Before using this skill, you should know:
- Which domain the entity belongs to
- Entity properties and their types
- Relationships with other entities
- Which fields need indexes

## Naming Conventions

### Database Objects

- **Tables:** snake_case, plural (`workspace_members`, `card_labels`)
- **Columns:** snake_case (`workspace_id`, `is_deleted`, `created_at`)
- **Indexes:** `idx_{table}_{columns}` (`idx_cards_list_pos`)
- **Foreign Keys:** `fk_{table}_{referenced_table}` (auto-generated by EF)

### C# Objects

- **Entities:** PascalCase, singular (`WorkspaceMember`, `CardLabel`)
- **Properties:** PascalCase (`WorkspaceId`, `IsDeleted`, `CreatedAt`)
- **Configurations:** `{EntityName}Configuration`
- **Migrations:** `{Verb}{Description}` (`AddCardLinkedPageId`, `CreateBoardViewsTable`)

## Template: Entity Configuration

```csharp
// File: backend/Notrelix.Infrastructure/Data/Configurations/CardConfiguration.cs
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;
using Notrelix.Domain.Entities.Board;

namespace Notrelix.Infrastructure.Data.Configurations;

public class CardConfiguration : IEntityTypeConfiguration<Card>
{
    public void Configure(EntityTypeBuilder<Card> builder)
    {
        // Table name
        builder.ToTable("cards");

        // Primary key
        builder.HasKey(x => x.Id);
        builder.Property(x => x.Id)
            .HasColumnName("id")
            .HasDefaultValueSql("gen_random_uuid()");

        // Properties
        builder.Property(x => x.ListId)
            .HasColumnName("list_id")
            .IsRequired();

        builder.Property(x => x.Title)
            .HasColumnName("title")
            .HasMaxLength(500)
            .IsRequired();

        builder.Property(x => x.Description)
            .HasColumnName("description")
            .HasMaxLength(10000);

        builder.Property(x => x.Position)
            .HasColumnName("position")
            .HasColumnType("float8")  // IMPORTANT: Use float8 for fractional indexing
            .IsRequired()
            .HasDefaultValue(0);

        builder.Property(x => x.DueDate)
            .HasColumnName("due_date")
            .HasColumnType("timestamptz");

        builder.Property(x => x.LinkedPageId)
            .HasColumnName("linked_page_id");

        // JSONB properties
        builder.Property(x => x.Cover)
            .HasColumnName("cover")
            .HasColumnType("jsonb")
            .HasDefaultValue("{}");

        // Audit fields
        builder.Property(x => x.CreatedAt)
            .HasColumnName("created_at")
            .HasColumnType("timestamptz")
            .IsRequired()
            .HasDefaultValueSql("NOW()");

        builder.Property(x => x.UpdatedAt)
            .HasColumnName("updated_at")
            .HasColumnType("timestamptz");

        builder.Property(x => x.CreatedBy)
            .HasColumnName("created_by");

        builder.Property(x => x.UpdatedBy)
            .HasColumnName("updated_by");

        // Soft delete
        builder.Property(x => x.IsDeleted)
            .HasColumnName("is_deleted")
            .IsRequired()
            .HasDefaultValue(false);

        builder.Property(x => x.DeletedAt)
            .HasColumnName("deleted_at")
            .HasColumnType("timestamptz");

        // Relationships
        builder.HasOne(x => x.List)
            .WithMany(x => x.Cards)
            .HasForeignKey(x => x.ListId)
            .OnDelete(DeleteBehavior.Cascade);

        builder.HasOne(x => x.LinkedPage)
            .WithMany()
            .HasForeignKey(x => x.LinkedPageId)
            .OnDelete(DeleteBehavior.SetNull);

        // Indexes
        // Composite index for list + position (with soft delete filter)
        builder.HasIndex(x => new { x.ListId, x.Position })
            .HasFilter("is_deleted = false")
            .HasDatabaseName("idx_cards_list_pos");

        // Index for linked page (with filter for non-null)
        builder.HasIndex(x => x.LinkedPageId)
            .HasFilter("linked_page_id IS NOT NULL AND is_deleted = false")
            .HasDatabaseName("idx_cards_linked_page");

        // Index for due date (for calendar queries)
        builder.HasIndex(x => x.DueDate)
            .HasFilter("due_date IS NOT NULL AND is_deleted = false")
            .HasDatabaseName("idx_cards_due_date");

        // Index for created_by (for user's cards)
        builder.HasIndex(x => x.CreatedBy)
            .HasFilter("is_deleted = false")
            .HasDatabaseName("idx_cards_created_by");
    }
}
```

## Template: Polymorphic Table Configuration

```csharp
// File: backend/Notrelix.Infrastructure/Data/Configurations/CommentConfiguration.cs
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;
using Notrelix.Domain.Entities.Shared;

namespace Notrelix.Infrastructure.Data.Configurations;

public class CommentConfiguration : IEntityTypeConfiguration<Comment>
{
    public void Configure(EntityTypeBuilder<Comment> builder)
    {
        builder.ToTable("comments");

        builder.HasKey(x => x.Id);
        builder.Property(x => x.Id)
            .HasColumnName("id")
            .HasDefaultValueSql("gen_random_uuid()");

        // Polymorphic fields
        builder.Property(x => x.WorkspaceId)
            .HasColumnName("workspace_id")
            .IsRequired();

        builder.Property(x => x.ResourceType)
            .HasColumnName("resource_type")
            .HasMaxLength(50)
            .IsRequired();

        builder.Property(x => x.ResourceId)
            .HasColumnName("resource_id")
            .IsRequired();

        // Content
        builder.Property(x => x.Content)
            .HasColumnName("content")
            .HasMaxLength(5000)
            .IsRequired();

        // Audit fields
        builder.Property(x => x.CreatedAt)
            .HasColumnName("created_at")
            .HasColumnType("timestamptz")
            .IsRequired()
            .HasDefaultValueSql("NOW()");

        builder.Property(x => x.UpdatedAt)
            .HasColumnName("updated_at")
            .HasColumnType("timestamptz");

        builder.Property(x => x.CreatedBy)
            .HasColumnName("created_by")
            .IsRequired();

        builder.Property(x => x.UpdatedBy)
            .HasColumnName("updated_by");

        // Soft delete
        builder.Property(x => x.IsDeleted)
            .HasColumnName("is_deleted")
            .IsRequired()
            .HasDefaultValue(false);

        builder.Property(x => x.DeletedAt)
            .HasColumnName("deleted_at")
            .HasColumnType("timestamptz");

        // Relationships
        builder.HasOne(x => x.Workspace)
            .WithMany()
            .HasForeignKey(x => x.WorkspaceId)
            .OnDelete(DeleteBehavior.Cascade);

        builder.HasOne(x => x.User)
            .WithMany()
            .HasForeignKey(x => x.CreatedBy)
            .OnDelete(DeleteBehavior.Restrict);

        // Indexes
        // Composite index for resource lookup
        builder.HasIndex(x => new { x.ResourceType, x.ResourceId })
            .HasFilter("is_deleted = false")
            .HasDatabaseName("idx_comments_resource");

        // Index for workspace (for workspace-level queries)
        builder.HasIndex(x => x.WorkspaceId)
            .HasFilter("is_deleted = false")
            .HasDatabaseName("idx_comments_workspace");

        // Index for created_by (for user's comments)
        builder.HasIndex(x => x.CreatedBy)
            .HasFilter("is_deleted = false")
            .HasDatabaseName("idx_comments_user");
    }
}
```

## Commands

### Create Migration

```bash
cd backend

# Add new migration
dotnet ef migrations add {MigrationName} \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API

# Examples:
dotnet ef migrations add AddCardLinkedPageId --project Notrelix.Infrastructure --startup-project Notrelix.API
dotnet ef migrations add CreateBoardViewsTable --project Notrelix.Infrastructure --startup-project Notrelix.API
dotnet ef migrations add AddBlockPropertiesJsonb --project Notrelix.Infrastructure --startup-project Notrelix.API
```

### Apply Migration

```bash
# Update database to latest migration
dotnet ef database update \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API

# Update to specific migration
dotnet ef database update {MigrationName} \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API

# Rollback to previous migration
dotnet ef database update {PreviousMigrationName} \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API
```

### Remove Migration

```bash
# Remove last migration (if not applied to database)
dotnet ef migrations remove \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API
```

### Generate SQL Script

```bash
# Generate SQL for all migrations
dotnet ef migrations script \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API \
  --output migration.sql

# Generate SQL for specific range
dotnet ef migrations script {FromMigration} {ToMigration} \
  --project Notrelix.Infrastructure \
  --startup-project Notrelix.API \
  --output migration.sql
```

## Important Rules

### DO

- ✅ Use `float8` (double) for position columns (fractional indexing)
- ✅ Use `timestamptz` for all datetime columns
- ✅ Use `jsonb` for flexible properties/metadata
- ✅ Add partial indexes with `WHERE is_deleted = false`
- ✅ Use `gen_random_uuid()` for UUID primary keys
- ✅ Use `NOW()` for default timestamps
- ✅ Set `HasMaxLength()` for string columns
- ✅ Use `OnDelete(DeleteBehavior.Cascade)` for owned relationships
- ✅ Use `OnDelete(DeleteBehavior.SetNull)` for optional references
- ✅ Use `OnDelete(DeleteBehavior.Restrict)` for user references
- ✅ Add indexes for foreign keys used in queries
- ✅ Add indexes for columns used in WHERE clauses

### DON'T

- ❌ Don't use `int` for position columns (use `float8`)
- ❌ Don't use `datetime` (use `timestamptz`)
- ❌ Don't forget partial indexes for soft-deleted entities
- ❌ Don't create indexes without filters when soft delete is used
- ❌ Don't use `OnDelete(DeleteBehavior.Cascade)` for user references
- ❌ Don't forget to add configuration to `ApplicationDbContext.OnModelCreating`
- ❌ Don't create duplicate polymorphic tables (use shared tables)
- ❌ Don't store binary data in database (use S3/R2)

## Column Type Mapping

### C# to PostgreSQL

```csharp
// Guid → UUID
builder.Property(x => x.Id).HasColumnType("uuid");

// DateTime → TIMESTAMPTZ (with timezone)
builder.Property(x => x.CreatedAt).HasColumnType("timestamptz");

// double → FLOAT8 (for fractional indexing)
builder.Property(x => x.Position).HasColumnType("float8");

// string → VARCHAR(n)
builder.Property(x => x.Title).HasMaxLength(500);

// bool → BOOLEAN
builder.Property(x => x.IsDeleted).HasColumnType("boolean");

// object/dynamic → JSONB
builder.Property(x => x.Properties).HasColumnType("jsonb");

// int → INTEGER
builder.Property(x => x.Count).HasColumnType("integer");

// decimal → NUMERIC(precision, scale)
builder.Property(x => x.Amount).HasColumnType("numeric(18,2)");
```

## Common Patterns

### Soft Delete Pattern

```csharp
// Always include both fields
builder.Property(x => x.IsDeleted)
    .HasColumnName("is_deleted")
    .IsRequired()
    .HasDefaultValue(false);

builder.Property(x => x.DeletedAt)
    .HasColumnName("deleted_at")
    .HasColumnType("timestamptz");

// Add filter to all indexes
builder.HasIndex(x => x.SomeColumn)
    .HasFilter("is_deleted = false")
    .HasDatabaseName("idx_table_column");
```

### Fractional Indexing Pattern

```csharp
// Use float8 for position
builder.Property(x => x.Position)
    .HasColumnName("position")
    .HasColumnType("float8")
    .IsRequired()
    .HasDefaultValue(0);

// Add composite index with container + position
builder.HasIndex(x => new { x.ContainerId, x.Position })
    .HasFilter("is_deleted = false")
    .HasDatabaseName("idx_items_container_pos");
```

### JSONB Properties Pattern

```csharp
// Use jsonb for flexible data
builder.Property(x => x.Properties)
    .HasColumnName("properties")
    .HasColumnType("jsonb")
    .HasDefaultValue("{}");

// Or for specific structured data
builder.Property(x => x.Cover)
    .HasColumnName("cover")
    .HasColumnType("jsonb")
    .HasDefaultValue("{}");
```

### Polymorphic Table Pattern

```csharp
// Always include workspace_id for RLS
builder.Property(x => x.WorkspaceId)
    .HasColumnName("workspace_id")
    .IsRequired();

// Resource type and ID
builder.Property(x => x.ResourceType)
    .HasColumnName("resource_type")
    .HasMaxLength(50)
    .IsRequired();

builder.Property(x => x.ResourceId)
    .HasColumnName("resource_id")
    .IsRequired();

// Composite index for lookups
builder.HasIndex(x => new { x.ResourceType, x.ResourceId })
    .HasFilter("is_deleted = false")
    .HasDatabaseName("idx_table_resource");
```

## Index Strategy

### When to Add Indexes

Add indexes for:
- Foreign keys used in JOINs
- Columns used in WHERE clauses
- Columns used in ORDER BY
- Composite keys for common query patterns
- Unique constraints

### Partial Indexes

Always use partial indexes to exclude soft-deleted rows:

```csharp
builder.HasIndex(x => x.ColumnName)
    .HasFilter("is_deleted = false")
    .HasDatabaseName("idx_table_column");
```

For nullable columns with filters:

```csharp
builder.HasIndex(x => x.LinkedPageId)
    .HasFilter("linked_page_id IS NOT NULL AND is_deleted = false")
    .HasDatabaseName("idx_cards_linked_page");
```

## Checklist

When creating a migration, ensure:

- [ ] Entity configuration created in `Configurations/` directory
- [ ] Table name is snake_case, plural
- [ ] All column names are snake_case
- [ ] Primary key uses `gen_random_uuid()`
- [ ] Position columns use `float8` (not `int`)
- [ ] Datetime columns use `timestamptz`
- [ ] Soft delete includes both `is_deleted` and `deleted_at`
- [ ] All indexes have partial filter for `is_deleted = false`
- [ ] JSONB columns have default value `{}`
- [ ] Foreign key relationships configured
- [ ] Appropriate `OnDelete` behavior set
- [ ] Configuration added to `ApplicationDbContext.OnModelCreating`
- [ ] Migration tested locally before committing

## Troubleshooting

### Migration Fails

```bash
# Check current migration status
dotnet ef migrations list --project Notrelix.Infrastructure --startup-project Notrelix.API

# View SQL that would be executed
dotnet ef migrations script --project Notrelix.Infrastructure --startup-project Notrelix.API

# Rollback to previous migration
dotnet ef database update {PreviousMigrationName} --project Notrelix.Infrastructure --startup-project Notrelix.API

# Remove failed migration
dotnet ef migrations remove --project Notrelix.Infrastructure --startup-project Notrelix.API
```

### Configuration Not Applied

Ensure configuration is added to `ApplicationDbContext.OnModelCreating`:

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.ApplyConfiguration(new CardConfiguration());
    // ... other configurations
}
```

Or use assembly scanning:

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.ApplyConfigurationsFromAssembly(Assembly.GetExecutingAssembly());
}
```
