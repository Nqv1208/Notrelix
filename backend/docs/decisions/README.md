# Backend Decisions

Backend ADRs preserve why consequential decisions were made. They are not
current architecture handbooks; current architecture lives under
`../architecture/`.

## Registry

- [ADR-001 Pipeline boundary](ADR-001-pipeline-boundary.md)
- [ADR-002 RLS bootstrap connection lifecycle](ADR-002-rls-bootstrap-connection-lifecycle.md)
- [ADR-003 CSRF protection](ADR-003-csrf-protection.md)
- [ADR-004 Rate limiting architecture](ADR-004-rate-limiting-architecture.md)

ADR IDs must be unique in this directory. If a decision changes, mark the old
ADR superseded and create a new ADR instead of rewriting history.
