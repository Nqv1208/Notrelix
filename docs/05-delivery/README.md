# Delivery Handbook

Delivery turns an accepted semantic change into a reviewable, migratable and supportable production change. Architecture ownership remains vertical through implementation; “backend team hands API to frontend team” is a coordination sequence, not a permanent architectural seam.

Read ownership, contract-first delivery, definition of done, rollout, onboarding and migration/change-impact guidance in this section.
