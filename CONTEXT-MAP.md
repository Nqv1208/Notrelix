# Context Map

This repository uses a multi-context domain layout for Notrelix enterprise platform.

## Bounded Contexts

- **Backend Context**: `backend/CONTEXT.md` (Clean Architecture + DDD + .NET Modular Monolith)
- **Frontend Context**: `frontend/CONTEXT.md` (Next.js / Vite + React + Domain packages)

## System-wide Architectural Decision Records (ADRs)

- System-wide ADRs live in `docs/adr/`.
- Context-specific ADRs live in `backend/docs/adr/` and `frontend/docs/adr/`.
